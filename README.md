# 小鲸鱼 · XiaoJingYu

一个只属于你自己的 AI 聊天 App —— 安卓单文件 APK，直连任意 OpenAI 兼容大模型。

- 🎭 多角色可切换，每个角色独立记录与记忆
- 🔌 多服务商：DeepSeek / OpenAI / Kimi / 智谱 / 通义 / SiliconFlow / OpenRouter / 本地 Ollama / 自定义
- 🌏 中英文界面 · 🖼 看图 · 🔍 联网搜索 · 🧠 笔记本记忆 · 😊 表情包 · 🎨 自定义背景 · 📤 聊天导出
- 🔒 不内置任何 API Key，只有联网权限

## 下载安装

到 Releases 下载 APK，安装后第一次打开：选服务商 → 填自己的 API Key → 测试连接。
